# Contribution au Projet

Merci de votre intérêt pour ce projet! Voici comment contribuer.

## 🐛 Signaler un Bug

1. Vérifiez que le bug n'a pas déjà été signalé
2. Créez une nouvelle issue avec:
   - Titre descriptif
   - Description détaillée
   - Étapes pour reproduire
   - Résultat attendu vs résultat réel
   - Environnement (OS, version Node, etc.)

## 🚀 Proposer une Fonctionnalité

1. Ouvrez une issue avec le label `enhancement`
2. Décrivez la fonctionnalité souhaitée
3. Expliquez le cas d'usage
4. Attendez la validation avant de développer

## 💻 Soumettre du Code

### Processus

1. Fork le repository
2. Créez une branche: `git checkout -b feature/ma-feature`
3. Committez vos changements: `git commit -m 'Add feature'`
4. Poussez: `git push origin feature/ma-feature`
5. Ouvrez une Pull Request

### Standards de Code

- Utilisez ESLint (configuration fournie)
- Maintenez une couverture de test > 80%
- Documentez les nouvelles fonctionnalités
- Respectez le style existant

### Structure des Commits

```
feat: Ajouter une nouvelle fonctionnalité
fix: Corriger un bug
docs: Mettre à jour la documentation
test: Ajouter ou modifier des tests
refactor: Refactoriser du code
```

## 📋 Checklist PR

- [ ] Changements testés localement
- [ ] Tests unitaires ajoutés/modifiés
- [ ] Documentation mise à jour
- [ ] Pas de console.log en production
- [ ] Message de commit descriptif

## 📚 Documentation

- Documentez les nouvelles API
- Mettez à jour le README si nécessaire
- Ajoutez des exemples pour les nouvelles fonctionnalités

## 🤝 Ligne de Conduite

- Soyez respectueux et inclusif
- Aidez les autres contributeurs
- Donnez un feedback constructif
- Signalez les comportements inappropriés

Merci de contribuer! 🎉
