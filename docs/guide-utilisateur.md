# Guide d'Utilisation - Gestion de Stock

## 🎯 Démarrage Rapide

### 1. Installation
```bash
npm install
npm run setup
npm start
```

### 2. Première Connexion
- **Email**: admin@inventory.com
- **Mot de passe**: admin123

## 📦 Gestion des Produits

### Ajouter un produit
1. Allez à "Produits" → "Nouveau produit"
2. Remplissez les informations
3. Cliquez "Créer"

### Modifier un produit
1. Cherchez le produit dans la liste
2. Cliquez sur "Modifier"
3. Mettez à jour les informations
4. Cliquez "Enregistrer"

## 📊 Gestion du Stock

### Enregistrer une entrée de stock
1. Trouvez le produit
2. Cliquez "Ajouter stock"
3. Entrez la quantité
4. Cliquez "Enregistrer"

### Enregistrer une sortie de stock
1. Trouvez le produit
2. Cliquez "Retirer du stock"
3. Entrez la quantité
4. Cliquez "Enregistrer"

## 📈 Rapports

### Inventaire général
- Vue d'ensemble par catégorie
- Quantités totales
- Valeur totale du stock

### Stock faible
- Produits sous le niveau de réapprovisionnement
